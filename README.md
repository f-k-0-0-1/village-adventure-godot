# 🎮 Village Adventure

A cozy 2D pixel-art adventure game built with **Godot 4.7**.

Explore a charming village, catch fish, complete quests, battle enemies, uncover hidden treasures, and discover new areas through exploration.

> 🚧 This project is currently under active development.

---

## ✨ Features

- 🏘️ Explore a handcrafted pixel-art village
- 🎣 Fishing system
- ⚔️ Light combat
- 📜 Quests and NPC interactions
- 🎒 Inventory system
- 🛒 Shops and economy
- 🌅 Day & night cycle
- 🌧️ Dynamic weather
- 🐟 Underwater exploration
- 💾 Save & load system
- 📱 Android support

---

## 🛠️ Built With

- **Engine:** Godot 4.7
- **Language:** GDScript
- **Platforms:** Android, Windows
